## About

I build software with a strong focus on **usefulness, clear interfaces and working releases**.

Most of my work is centered around **Python, Windows desktop applications and automation**, with additional projects in web development, Android, media tooling, browser utilities and game development.

I prefer solving a concrete problem first, releasing a usable version early, and improving it through iteration.
