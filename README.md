I’m **Świr**, an independent developer building **Windows desktop tools, automation and everyday utilities**, alongside Android, web and game projects.

My work focuses on turning repetitive tasks into straightforward applications: managing downloads, organising photos, processing files and tracking working time. I also explore game systems and AI-assisted development.
